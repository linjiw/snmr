\title{A Clock Can Track: Why Motion-Tracking Success\\Does Not Identify What a Learned Command Carries}

\author{Anonymous ICRA Submission}

\begin{abstract}
A tracking policy whose only motion command is absolute time completes more rollouts than
one commanded by a frozen multi-embodiment retargeting latent: $0.754\pm0.010$ against
$0.656\pm0.044$ on a single deterministic simulated Unitree~G1 walk.  Tracking success
therefore does not identify what a learned command carries---on one clip the clock indexes
the entire target, so any channel correlated with progress inherits its score.  We make the
interface measurable instead: a 64-d code is the decoder's exclusive motion command, and a
policy-independent screen builds \ESelectedWindows{} start pairs whose present states are
close but whose futures diverge, breaking the one-to-one link between time and target.
Under that construction the frozen latent leads an equally trained clock by
$\EATDifference$ [\EATCILow, \EATCIHigh] and a matched-phase wrong-trajectory control by
$\EASDifference$ [\EASCILow, \EASCIHigh] in the \EEndpointLabel.  Destroying the exclusive
command collapses completion to \EDestroyCompletion{} in all \EDestroySeeds{} seeds and all
\EDestroyModes{} destruction modes, on \emph{both} the explicit and latent arms.  Shifting
the latent in time---which preserves clip identity exactly---destroys
\EPhaseShiftPlusHalfLostPercent\% of that advantage at $\EPhaseShiftPlusHalfSeconds$\,s,
so the command carries time-aligned trajectory state rather than a static clip label.  The
contribution is a reproducible contract for auditing learned humanoid motion interfaces
under shortcut-matched controls, together with the scope its own instrument can support.
\end{abstract}

\section{Introduction}

Learned command latents are increasingly used in humanoid control, but tracking success
does not reveal what the controller actually receives from them.  On a deterministic
reference clip, absolute time indexes every target, so motion-specific content and
progress through the clip are observationally indistinguishable.  We find this is not a
hypothetical: on a single simulated Unitree~G1 walk, a policy whose only motion command
is a fixed projection of absolute frame index completes $0.754\pm0.010$ of rollouts,
\emph{above} the $0.656\pm0.044$ reached by a frozen multi-embodiment retargeting latent
carrying no robot-space reference at all.  A clock can track.  Any evaluation that scores
a learned command by tracking success alone inherits that confound.

The confound is structural, not incidental to our system.  Modern humanoid stacks split
into a retargeter that converts human motion into robot-space joint trajectories and a
reinforcement-learning policy that tracks them~\cite{deepmimic}.  The split is useful, and
both sides are strong: interaction-preserving optimization on the retargeting
side~\cite{omniretarget}, physics-in-the-loop retargeting~\cite{reactor}, and unified
trackers that follow thousands of clips with one network~\cite{beyondmimic,gmt}.  But the
\emph{interface} between them is rarely the object of study, and whenever a reference
clip determines its own target from a time index---which is the standard evaluation
protocol---credit for tracking success cannot be attributed to any candidate command
channel.  The same applies to skill latents, demonstration-conditioned controllers, and
learned motion tokens.

Simply concatenating the retargeter's latent beside the explicit reference is null in our
baseline: the policy takes the more informative channel.  Our latent-command RL baseline
also collapses; recent systems instead use staged distillation or representation
pretraining~\cite{unitracker,bfm}.  What has been missing is not another repair but a
measurement.

\textbf{Our key insight is that exclusivity makes the interface experimentally
measurable.}  If a learned code is the policy's only route to the goal, then changing the
signal that feeds the code and measuring closed-loop completion tests what the controller
can use.  A deterministic single-trajectory test remains confounded because absolute
time identifies the target.  We build the instrument from \snmr{}, a retargeting network
distilled from a classical IK teacher whose shared latent serves five humanoids, and a
64-d command code trained by online distillation from an explicit-command RL
teacher~\cite{dagger}.
The goal is visible to the code encoder and never to the action decoder
(\S\ref{sec:method}).

On a simulated Unitree~G1 the learned interface matches the evaluated
explicit-command teacher checkpoint on one walk (three student seeds, one teacher
checkpoint), but the frozen retargeting latent loses to an absolute-time control.  We
turn that negative diagnostic into the two-walk paired assay in
Fig.~\ref{fig:teaser}c.  A world-body indexing defect found during calibration is kept
as a validity audit: repairing it cut joint RMSE by 46\%, and all interface results
reported here were rerun after repair (\S\ref{sec:defect}).

\textbf{Contributions.}
\begin{itemize}
\item \textbf{Deterministic-clip non-identifiability, demonstrated.}  A clock-commanded
  policy outperforms a frozen retargeting latent on a single walk.  Tracking success on a
  deterministic clip cannot identify motion-specific command content, and we show the
  ordering this induces is not merely possible but actual.
\item \textbf{An exclusive command interface with a verified within-policy intervention.}
  A 64-d code is the decoder's only goal channel.  Zero, shuffle, and matched-marginal
  destruction collapse completion to \EDestroyCompletion{} in all \EDestroySeeds{} training
  seeds and all \EDestroyModes{} modes, on \emph{both} the explicit arm
  (\EDestroyBaselineCompletion{} intact) and the latent arm
  (\EDestroySnmrBaselineCompletion{} intact), separating structural exclusivity from
  behavioral dependence.
\item \textbf{A paired assay for content beyond time, and a test of what that content is.}
  A policy-independent search yields \ESelectedWindows{} two-walk starts with similar
  present states and different futures.  Under one frozen recipe,
  \ifeexplicitvalid\ifepositivecontent the latent passes the registered content gate over
  absolute time and phase-matched shuffled content\else the explicit control passes but the
  latent does not pass the registered content gate\fi\else the explicit control fails, so
  the representation comparison is invalid\fi.  A time-shift battery, which preserves clip
  identity exactly, then separates a static clip label from time-aligned trajectory state.
\item \textbf{Controls, declared limits, and reproducible failure boundaries.}  The
  single-clip time null retires a favorable prior claim of our own; specialist and
  explicit-student gates isolate representation from task feasibility; and we measure and
  report our own evaluation-replication floor rather than assuming determinism.
\end{itemize}
These controls also falsified three earlier working hypotheses of ours; we retain those
outcomes rather than selecting only favorable experiments.

\section{Related Work}
\textbf{Retargeting as preprocessing.} Classical retargeting solves per-frame IK with
hand-tuned correspondences~\cite{gmr}; interaction-mesh methods add hard contact
constraints~\cite{omniretarget}; ReActor moves retargeting inside physics via bilevel RL,
eliminating artifacts by construction~\cite{reactor}. All three families emit the same
interface---robot joint trajectories---and are evaluated by kinematic quality plus,
recently, downstream RL success~\cite{gmr,omniretarget}. These works do not treat the
\emph{representation} handed to the tracker as the experimental object. Neural feed-forward
retargeters~\cite{ikmr,nmr,adamorph} amortize the optimization and, in AdaMorph's case,
span many embodiments through a morphology-agnostic latent---but their latents are
internal machinery rather than evaluated command interfaces.

\textbf{Tracking and its command spaces.} Modern trackers follow references specified as
joint targets with body-pose terms~\cite{beyondmimic,gmt,exbody2}, now at foundation
scale~\cite{sonic,humanoidgpt}; HOVER unifies multiple
command \emph{modes} by distillation~\cite{hover}; UniTracker compresses the reference
into a CVAE latent and is the closest precedent for our command interface---single-embodiment, with
no retargeter and no representation analysis~\cite{unitracker}. Latent skill spaces for
physics characters~\cite{pulse,maskedmimic,controlvae} establish code-mediated control;
our calibration ablation instead selects a deterministic encoder for the frozen assay.
Behavioral foundation models~\cite{bfmzero} reach a promptable
latent from the opposite entry point---unsupervised RL without a retargeting stage.
Capability benchmarking in the HOVER/ULTRA class~\cite{hover,ultra} asks how broadly or
accurately a controller can be commanded; that axis is orthogonal to representation
measurement---what information crosses an exclusive interface and is used. RoboGhost
bypasses explicit retargeting by conditioning control on a
language-grounded motion latent~\cite{roboghost}, while ULTRA distills a tracker into a
multimodal latent controller~\cite{ultra}, AnyBody distills a tracker into a
keypoint-addressable latent~\cite{anybody}, and HANDOFF engineers a compact task-space
command, arguing that the interface choice is decisive~\cite{handoff}. For dense
tracking, however, ULTRA sends the full-body goal to the decoder through a residual
shortcut, and all of these engineer the channel rather than measure it. Our exclusivity
contract instead makes the learned code the only goal channel and tests a frozen
multi-embodiment retargeting latent as one possible source for that code.

\textbf{Interface critiques and measurement.} BeyondMimic names a ``planning-control
gap''~\cite{beyondmimic}; the GMR study quantifies how retargeting quality caps
tracking~\cite{gmr}. Recent work sharpens the concern: a controlled study of explicit
command signals finds proprioceptive history does not recover reference phase and
velocity~\cite{whatmatters}; OmniTrack and GenTrack intervene on the boundary by
replacing references with dynamics-consistent ones~\cite{omnitrack,gentrack}; and
benchmark audits report that tracking metrics conflate motion difficulty with policy
quality~\cite{mds} and that hierarchical results are
tracker-conditioned~\cite{humanoidarena}. None makes the interface itself the object of
a controlled causal measurement. Our instrument imports the missing methodology:
probing classifiers and their documented gap between decodability and
use~\cite{linearprobes,probingsurvey}, interventions that ablate information and
measure behavior rather than decode it~\cite{amnesic}, usable information under
computational constraints~\cite{vinfo}, and preregistered
endpoints~\cite{prereg,preregml}; the single-trajectory clock of \S\ref{sec:exp} is an
instance of shortcut learning~\cite{shortcut}.

\section{The Instrument: A Learned Code Under an Exclusivity Contract}
\label{sec:interface}
A source motion $m_t$ enters a retargeter $R$; the standard interface hands the tracker
$\pi$ a 64-d reference $g_t=(q^{\mathrm{ref}}_t,\dot q^{\mathrm{ref}}_t,
r^{\mathrm{ref}}_t)$: 29 joint positions, 29 velocities, and a 6-d relative reference-orientation
representation. We move the actor-visible reference behind a learned code:
$\zcmd = E_\theta(x_t,u_t)$, where $u_t=g_t$ in the explicit arm and
$u_t=[z_{\mathrm{ret},t},z_{\mathrm{ret},t+0.1\,\mathrm{s}}]$ in the \snmr{} arm.
The explicit command is current-frame only; an explicit future-goal window remains
future work. Under an \emph{exclusivity contract}, the upstream signal is visible to the
encoder $E_\theta$, but never to the action decoder, whose input is exactly the
90-d proprioceptive slice plus the 64-d code (structurally regression-tested).  Behavioral
dependence is established within each trained policy: zeroing, batch-shuffling, or
independently resampling each observed marginal of \zcmd{} collapses completion to
\EDestroyCompletion{} in every one of the \EDestroySeeds{}~seeds $\times$
\EDestroyModes{}~modes, on both arms---the explicit student falls from
\EDestroyBaselineCompletion{} and the latent student from
\EDestroySnmrBaselineCompletion{}.  Destruction drives the latent arm \emph{below} the
goal-blind proprioception control (\EProprioGeneral{}), so a destroyed channel is not a
stand-in for a controller that never had one; the intervention places the input far
outside the training distribution.  We use ``interface,'' not ``bottleneck'': the code is
not dimensionally narrower than the goal (64-d each), and no rate term constrains the
goal-to-code path. Linear diagnostics find effective rank 14 of 64 and lower goal
decodability from the deployed code than from proprioception (held-out $R^2$ 0.48 vs
0.62); these were measured on the explicit arm and characterize the shared code rather
than the latent source, and they do not establish an information
bound.
The encoder's upstream source is the experimental factor (\S\ref{sec:exp}).  Across our
diagnostics it can be the robot-space reference $g_t$, the source-side representation
$z_{\mathrm{ret}}$ alone (with no robot-space reference anywhere in the student), both
signals, absolute time, or proprioception alone.  E70 freezes the five-arm comparison
C/A/T/B/S defined in \S\ref{sec:exp}.

\textbf{Operational estimand.}  Let $x_t$ be actor-visible proprioception, $u_t$ the
candidate upstream signal, $E$ the learned command encoder, and $D$ the action decoder:
\begin{equation}
  z_t=E(x_t,u_t), \qquad a_t=D(x_t,z_t), \qquad u_t\not\rightarrow D\;\text{otherwise}.
\end{equation}
For rollout completion $Y$, the quantity of interest is not mutual information in
$z_{\mathrm{ret}}$ but a contrast between policies produced by the fixed training
algorithm:
\begin{equation}
  \Delta_{A,T}=\mathbb{E}[Y(D_A(x,E_A(x,z_{\mathrm{ret}})))-
  Y(D_T(x,E_T(x,\tau)))],
\end{equation}
where $\tau$ is matched within-clip time.  The arms share the
teacher ensemble, core architecture, training budget, initialization seed, and
evaluation starts; their closed-loop training states may differ.  C verifies
that the student class can transmit a sufficient goal; B measures what closed-loop
proprioceptive memory can do without a goal; S supplies the other trajectory's latent at
matched normalized time.  Finally, interventions on the
\emph{learned} $z_t$ test whether the structurally exclusive route is actually used.
These controls replace the broad statement ``the latent contains information'' with the
narrower operational claim we can test: under a frozen training and evaluation protocol,
a policy trained from the latent achieves different physical task success from one
trained from time.  Only the within-policy \zcmd{} destruction tests are causal
interventions on a fixed trained controller.

The latent's source is \snmr{}: a graph-attention encoder over the source skeleton
(per-node features, adjacency, and global pooling) maps
motion to a per-frame retargeting latent $z_{\mathrm{ret}}\in\mathbb{R}^{128}$
(distinct from the control code \zcmd{}); embodiment-conditioned graph
decoders (AdaLN on a 32-d embodiment code, $\tanh$ joint-limit heads) emit trajectories
for the five training humanoids. Trained by distillation from a per-frame IK
teacher~\cite{gmr} on 77 LAFAN1 clips $\times$ 5 robots (2.48M paired frames), it
reaches 3.66\,cm held-out MPJPE (CI $[3.46, 3.86]$; G1 specialist; 2.9--6.0\,cm shared
across all five robots) at 671\,fps on CPU, with zero joint-limit violations by
construction. Foot skate (0.29 vs teacher 0.05\,m/s) remains a measured fidelity gap.

The reported instrument (Fig.~\ref{fig:loop}) is deterministic. The \textbf{encoder}
$E_\theta:(x,u)\mapsto\zcmd$ sees 90-d proprioception and only the arm-specific upstream
signal---the current 64-d explicit goal or the two-sample 256-d \snmr{} latent window.
For the latter, a learned projection maps 256 to 64 dimensions before a
$512$--$256$ MLP emits \zcmd{}. The \textbf{decoder} is a $512$--$256$--$128$ MLP
that maps $(x,\zcmd)$ to 29 PD targets at 50\,Hz and never sees $u$. Gradients from
teacher-action MSE update both modules; no RL gradient enters the student.

Rollouts mix the routed specialist teacher with the student at probability
$p_r=\max(0.1,1-r/200)$, and the frozen teacher labels every visited state. Each of
2,000 rounds collects 24 steps in 1,024 environments, then runs five Adam epochs on a
four-round FIFO buffer. A fixed 4,096-sample round-0 validation split selects the
lowest teacher-action-loss checkpoint after round 50; rollout completion never selects
a checkpoint. A controlled calibration ablation chose this simple model: a
deterministic 64-d explicit-goal encoder reached 0.969 completion, within the earlier
CVAE variant's range. Posterior, KL, sampling noise, and smoothness are therefore not
ingredients of E70. Earlier posterior-path and goal-free variants collapsed at
deployment; they motivated deployment-path collection and goal conditioning but are
not pooled with the reported assay.

\section{Experiments: From a Clock Confound to a Paired Assay}
\label{sec:exp}
We evaluate deterministic deployment on a simulated Unitree~G1 in
MuJoCo-Warp~\cite{mujoco}.
\emph{Completion} is the fraction of 10-s rollouts that remain inside the standard
tracking tube: anchor drift $\leq0.5$\,m, body-orientation error $\leq0.8$\,rad, and
end-effector deviation $\leq0.25$\,m.  Every reported student evaluation uses 1,024
rollouts and seed 404.  Students use the same 2,000-round online-distillation recipe:
1,024 environments, 24-step collection, four-round replay, five epochs, Adam
$3{\times}10^{-4}$, and validation-selected checkpoints.  All results postdate the two
measurement repairs in \S\ref{sec:defect}.

\subsection{Diagnostic 1: a single trajectory is a clock}
On LAFAN1~\cite{lafan1} \texttt{walk1\_subject5}, an explicit-command student matches its evaluated
teacher checkpoint (completion $0.955\pm0.008$ vs 0.954; three student seeds, one
teacher checkpoint).  A frozen human-side $z_{\mathrm{ret}}$ achieves
$0.656\pm0.044$ with no robot-space reference, far above a proprio-only encoder at
$0.001\pm0.001$.  Yet a fixed random projection of absolute frame-index sinusoids,
passed through the same command path, reaches $0.754\pm0.010$.  Because time
uniquely identifies a deterministic clip, this null retires any single-clip claim that
the latent supplies usable content beyond time; it does not bound information in the
latent.  (This single-clip clock value coincides numerically with the two-walk latent
completion in Table~\ref{tab:main}; the two are unrelated quantities measured on
different start distributions, and we report the two-walk result through paired contrasts
throughout to avoid the collision.)  Adding $z_{\mathrm{ret}}$ beside the explicit goal is also null
($0.956\pm0.003$), consistent with a stronger redundant channel being used instead.

\subsection{Diagnostic 2: matched presents with different futures}
We froze a policy-independent two-trajectory assay before training any student.  From
the 77-clip LAFAN1 corpus, a reference-only screen paired 75 candidates with the fixed
passing \texttt{walk1\_subject5} anchor; the anchor and a previously closed candidate
were excluded.  Current perfect-tracking states are
standardized joint positions and velocities; a pair is eligible when current RMS
distance is at most 0.75 pooled SD but its 1-s future distance (11 samples) is at least
0.75 SD.  Starts must be 0.5\,s apart and retain a full same-clip 10-s rollout.  The
frozen selector ranked passing candidates first by lowest reference difficulty, then by
window count and future divergence.  It chose \texttt{walk1\_subject1}: \ESelectedWindows{} pairs,
median future distance \ESelectedMedianFuture{} SD (the median over the \EEligibleWindows{}
threshold-eligible windows, before selection, is \EEligibleMedianFuture{}).
Its specialist and the anchor specialist independently
pass the same 1,024-rollout gate (0.987 and 0.847 completion; macro 0.917).  The search
is policy-independent but intentionally favors a feasible tracking pair.

The five student arms share the teacher ensemble, student core, training budget,
checkpoint rule, and evaluation starts; they differ in the upstream signal available to
the encoder: explicit robot goal (C), frozen SNMR latent at $t$ and $t{+}0.1$\,s (A),
absolute within-clip time (T), proprioception alone (B), or the other clip's latent at
matched normalized time (S).  C runs first and
must reach 0.80 general completion or fall no more than 0.05 below the specialist
macro.  Only then are A/T/B/S licensed.  The primary endpoint is ambiguity-start
completion; a paired bootstrap clusters by the 69 frame pairs, and the registered
content gate requires A--T $\geq0.10$, A--T and A--S intervals excluding zero, and a
positive A--T direction on both clips.  T uses 16 log-spaced sine/cosine pairs followed
by one fixed seed-63 random projection to 128 dimensions; the code resets identically at
each clip boundary, contains no motion ID or global offset, and uses the same two-frame
window as A.

\subsection{Diagnostic 3: a clip label cannot be misaligned in time}
\label{sec:phase}
The contrasts above establish that the latent carries clip-disambiguating information, but
not what that information is.  The sharpest competing account is that \zcmd{} carries a
single bit---\emph{which clip}---which on two memorized walks would reproduce the entire
A--T gap.  The shuffled control cannot separate this, because it destroys clip identity and
future correctness together.

A time shift does separate them.  We replace the source window
$[z_{\mathrm{ret},t},z_{\mathrm{ret},t+0.1\,\mathrm{s}}]$ with
$[z_{\mathrm{ret},t+\delta},z_{\mathrm{ret},t+\delta+0.1\,\mathrm{s}}]$ from the
\emph{same} clip: a real latent trajectory with the same marginal statistics and the same
internal window structure, differing only in alignment to the physics.  Clip identity is
preserved exactly, so a one-bit clip label predicts \emph{no effect}, while time-aligned
trajectory state predicts degradation growing with $|\delta|$.  The intervention is
delivered by substituting only the $\mathrm{latent}\_z$ field of the motion archive, so the
frozen students, the reference target, and the scoring tube are untouched.  Each arm is run
\EPhaseRepeats{} times per seed on all \EPhaseSeeds{} seeds; differences below
\EPhaseFloor{} completion are reported as within evaluation noise
(\S\ref{sec:limits}).

Degradation is monotone in $|\delta|$, symmetric in sign, and consistent across every seed.
Against the control at \EPhaseControlCompletion{}, a shift of
$\EPhaseShiftMinusQuarterSeconds$\,s gives \EPhaseShiftMinusQuarterCompletion{} and
$\EPhaseShiftPlusQuarterSeconds$\,s gives \EPhaseShiftPlusQuarterCompletion{}, each
destroying roughly half of the latent's \EPhaseClockAdvantage{} advantage over the clock;
$\EPhaseShiftPlusHalfSeconds$\,s gives \EPhaseShiftPlusHalfCompletion{}, destroying
\EPhaseShiftPlusHalfLostPercent\% of it.  Half a second of phase error leaves the latent
barely above the matched-phase wrong-trajectory control (\EShuffledAmb{}) and
indistinguishable from the clock (\ETimeAmb{}).  \textbf{Clip identity and temporal
alignment are each necessary; neither alone is sufficient}, and a static clip label is
rejected.

Two static-code arms were registered alongside: replacing the window with a clip-constant
first-frame code gives \EPhaseFirstFrameCompletion{} and a clip-mean code
\EPhaseClipMeanCompletion{}.  Both collapse, and we registered in advance that this
licenses nothing---a constant code is outside the student's training input distribution,
which always saw $z_{\mathrm{ret},t}\neq z_{\mathrm{ret},t+0.1\,\mathrm{s}}$, so collapse
is confounded with distribution shift.  Retention would have been evidence for identity;
collapse is not evidence for content.  The shift arms carry the result because they alone
are two-sided.

We claim sensitivity, not steering.  The battery shows the controller's behavior
\emph{depends on} the command's temporal alignment; it does not show the rollout moves
\emph{toward} the shifted target, which would require a branch coordinate we do not
measure.  Both readings defeat a static clip label---a label reader would not notice a
shift at all---so the rejection holds either way.

\section{What the Upstream Latent Exposes}
\label{sec:audit}
Before asking the latent to carry control, we measured what it holds. Four pre-specified
probe families, in increasing severity:

\textbf{Content: instance-aligned, not linearly semantic.} Cross-embodiment
\emph{window} retrieval hits 75--83\% top-1 at 1.02\% chance on four embodiments and
57\% on the fifth (the morphological outlier); CKA between per-robot encodings is
0.86--0.92. A \emph{linear} motion-category probe is near chance (0.151 vs 0.125).
We therefore claim only that motion category is not linearly accessible; exploratory
low-dimensional visualizations do not establish nonlinear decodability.

\textbf{Embodiment: aligned, not invariant.} A linear probe recovers the source
embodiment at only 0.28 accuracy, but a nonlinear attacker reaches 0.91---the classic
gap between ``not linearly decodable'' and ``absent.'' A height-normalization
intervention moves the attacker only $\sim$1\,pp, suggesting---though, being an
out-of-distribution intervention, not proving---that body scale is a minor share of
the leak.

\textbf{Physics: weakly exposed.} Foot-contact state is poorly linearly decodable under
pure distillation: F1 is 0.088 at full budget, below the deployable source-height
heuristic at 0.127, and AUROC is 0.51--0.64 on the only clip with balanced label
support. A co-trained contact head raises latent-probe F1 to 0.227 at full budget
($1.8\times$ the heuristic) but costs $+1.5$\,cm MPJPE at loss weight 0.5.  Contact thus
becomes substantially more accessible only when it is explicitly supervised, with a
measurable fidelity tradeoff.

\textbf{Control: useful when exclusive, redundant beside explicit targets.} Through the
distilled encoder of \S\ref{sec:exp}, adding the latent beside the explicit reference is
null ($0.956$ vs $0.955$).  This is consistent with the explicit channel dominating
when it remains available.  When the latent is exclusive and two
trajectories make time
ambiguous, \ifeexplicitvalid\ifepositivecontent its instance-aligned structure becomes
control-usable\else the registered assay does not demonstrate control value over its
matched content controls\fi\else the failed capability control prevents a downstream
representation conclusion\fi{} (\S\ref{sec:exp}).  The probes show that the frozen latent
exposes trajectory identity and pose evolution, but little linearly accessible
semantics or contact physics; the controller assay separately tests whether the decoder
can use that content.

\section{A Defect in the Measurement Substrate}
\label{sec:defect}
Calibration found two measurement defects before the reported assay was frozen.  First,
MuJoCo-Warp state tensors include the world body while the corresponding name list does
not; an off-by-one in our pinned stack made the body-position reward exactly zero.
Correcting the index cut joint RMSE from 0.263 to 0.142\,rad without changing the
learning algorithm.  Second, observation terms are concatenated alphabetically, while
our first distillation implementation sliced them in configuration order.  The decoder
therefore received an explicit-goal shortcut inside its nominal proprioception; blanking
the leaked dimensions collapsed completion from 0.93 to 0.00.  We replaced positional
slices with name-derived indices and regression-test the decoder's exact 90-d
proprioceptive contract.  Every interface result in this paper was retrained after both
repairs.  The validity lesson is methodological: structural channel assertions require
layout tests, and structural exclusivity still requires a causal intervention.

\section{Reproducibility Contract}
The reproducibility record separates small immutable evidence from generated training
outputs.  It includes the SNMR package, interface trainer, name-derived observation
layout tests, reference-only selector, launchers, paired analyzer, exact environment
pins, and machine-readable protocol records.  The E70 record freezes ordered motion
hashes, both specialist checkpoint and evaluation-report hashes, the transformed
69-pair start grid, student recipe, seeds, gates, and outcome language.  The launcher
uses a new E70 root, refuses either failed specialist, evaluates C before any
representation arm, and writes reports atomically; completed cells are hash-checked and
skipped on resume.  Each report stores all 1,024 start steps, completion indicators,
survival and error vectors, motion IDs, teacher checkpoints, arm configuration, and
evaluation seed.  The analyzer verifies exact pairing before computing a result and
records SHA-256 for every input in its output.  Large LAFAN1/GMR-derived motions,
teacher checkpoints, and student checkpoints are excluded from the review PDF but have
deterministic preparation commands; no external artifact is required to understand the
claims in Table~\ref{tab:main}.

\section{Limitations}\label{sec:limits}
The \ifepositivecontent positive content result\else registered assay outcome\fi{} is
deliberately narrow: two similar LAFAN1 walks, one
simulated Unitree~G1, one frozen SNMR endpoint, one specialist ensemble, and one
distilled controller class.  Both evaluation motions are student-training trajectories:
the ambiguity starts change the start distribution but do not test held-out-motion
generalization.  The matched time null rules out absolute progress through
these clips, not every temporal or phase model; the shuffled control destroys clip
identity as well as future correctness, so a positive result establishes
clip-disambiguating information but does not separate static clip identity from finer
time-varying future semantics.  Nearby starts can also have overlapping 10-s rollout
horizons; the preregistered interval is conditional on these two trajectories and
\ESelectedWindows{} reference-defined starts and does not model temporal dependence across
pair identities.  A preregistered secondary analysis over \ETemporalBlocks{} connected
temporal blocks addresses that dependence without changing the primary analysis, and
reproduces it: A--T $\ETemporalATDifference$
[\ETemporalATCILow, \ETemporalATCIHigh] and A--S $\ETemporalASDifference$
[\ETemporalASCILow, \ETemporalASCIHigh], both directionally consistent with intervals
excluding zero.
\ifethreeseed The primary table is the
preregistered three-seed aggregate.\else The primary table is the preregistered seed-0
endpoint while two additional training seeds are being run without tuning; final
submission claims must include them.\fi{}
\ifeexplicitvalid\ifepositivecontent The assay establishes control-usable information,
not an information-theoretic property of $z_{\mathrm{ret}}$.\else The scoped null does
not establish that the code lacks information; it only fails to demonstrate content
use under this frozen controller and assay.\fi\else The failed explicit capability gate
invalidates any A--T or A--S interpretation.\fi{} No outcome shows additive benefit
beside an explicit target.  The upstream SNMR encoder is frozen, so no tracking
gradient improves what it exposes.  Zero-shot decoding to an unseen robot fails
($5.2\times$ error), contact is weak without explicit supervision, object and terrain
interaction are absent from the tracking loop, and no hardware or sim-to-real result is
reported.

\textbf{Precision we do not claim.}  Two components of uncertainty are not in the
registered interval, and we report both rather than let a replication attempt discover
them.  First, the estimand in \S\ref{sec:exp} makes the training run the sampling unit,
and across training seeds \ETrainingSeeds{} a $t$-interval on A--T is
[\ESeedLevelATLow, \ESeedLevelATHigh]---its lower bound is near zero and below our own
registered $0.10$ threshold, and a three-seed sign test cannot reach conventional
significance under any outcome, so we do not report one.  The registered bootstrap is
conditional on these three controllers and is not inference over a population of newly
trained policies.  Second, the evaluation itself is not bit-reproducible: re-running one
arm under identical inputs changes about \EReplicationFlipPercent\% of individual rollout
outcomes, because closed-loop rollouts amplify nondeterminism until near-threshold
episodes flip.  Over eight repeats the per-arm completion standard deviation is
\EReplicationSd{}, and because the noise is largely common-mode the paired contrast is far
more stable than either arm; propagating it widens the primary interval by
\EReplicationWidenPercent\%, to [\EReplicationATLow, \EReplicationATHigh].  Neither
adjustment changes a verdict.

\textbf{What the instrument cannot see.}  Completion is a tracking predicate, not a safety
one: a controller that safely ignores a corrupted command and stands still scores
identically to one that falls.  Nothing here should be read as a robustness or safety
claim about learned command interfaces, and we do not make one.  Relatedly, the
goal-blind proprioception arm reaches \EProprioAmb{} on the ambiguity starts while the
same control reaches $0.001\pm0.001$ on the single-clip diagnostic; the two-walk tube
admits a substantially higher goal-free floor, which compresses the usable dynamic range
above ``know nothing'' and is the reason we report paired contrasts rather than absolute
margins.  Null-arm ordering is also unstable across seeds---in one seed the shuffled
control exceeds the time control---so we define contrasts against named arms rather than
against whichever null happens to be strongest.

\section{Conclusion}
A clock can track.  On a deterministic reference clip, absolute time indexes the entire
target, so tracking success cannot identify what a learned command carries---and in our
single-clip test a clock-commanded policy in fact beats a frozen retargeting latent.  That
negative diagnosis is the paper's starting point, not an aside.

The repair is to make the command exclusive and to construct starts whose presents match
while their futures diverge.  Under that construction the boundary becomes measurable, and
\ifeexplicitvalid\ifepositivecontent the frozen latent shows a registered advantage over
both an equally trained clock and a matched-phase wrong-trajectory control\else the
registered content gate does not pass\fi\else the explicit capability control fails and no
representation comparison is supported\fi.  Within-policy destruction shows both arms
depend on the exclusive channel, and a time-shift battery---which preserves clip identity
exactly---shows the content is time-aligned trajectory state rather than a static clip
label.

The contribution is not a universal latent, a better tracker, or a hardware claim.  It is a
reproducible contract for asking what a learned command interface actually supplies to
control, applied to one retargeting latent on two known walks, together with an honest
account of what that instrument cannot resolve.
