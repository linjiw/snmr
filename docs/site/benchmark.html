Why the teacher column matters. OmniRetarget and ReActor both report baselines' artifacts; the GMR paper shows every retargeter has them (PHC: 60 cm penetrations; GMR itself: waist-roll jumps on Dance 5). Scoring the student against a perfect-zero column would be dishonest — the teacher's 0.052 m/s skate is the distillation floor, not zero.

Per-clip breakdown (G1, 7 held-out clips)

The GMR paper's key finding is that aggregate tables hide the failures — per-motion breakdowns reveal them. Ours: MPJPE is stable across categories (3.3–4.1 cm); skate is worst on locomotion clips (walk/run/dance) where stance phases dominate; jumps1 is the penetration outlier for both student and teacher (landing frames).

One network, five embodiments (shared checkpoint)

The multi-embodiment claim, quantified. A single shared-latent network (z=128, AdaLN embodiment conditioning) serves all five robots; the sharing cost vs the G1 specialist is ~2.4 cm (6.04 vs 3.66). No per-robot IK configs, no per-robot tuning — and inference stays real-time on CPU for every embodiment.

Downstream RL trackability (the GMR-paper question)

"Retargeting Matters" evaluates retargeters by what RL can learn from their output. Same protocol here: matched tracking policies (3 seeds per source × 2 eval seeds × 100 rollouts), identical hyperparameters, on the same walk1 clip.

Scope, honestly. Single clip (walk1), single robot (G1), simulation only, both sources trained under the identical stack. The claim this supports: neural retargeting through a shared latent does not degrade downstream trackability relative to its IK teacher — not that it improves it. Multi-clip trackability is running now (E53).

Protocol notes

Held-out clipswalk1, dance2, fight1, run2, jumps1, sprint1, aiming2 (never trained on; fixed split since Phase 1)
Foot skatemean XY stance-foot speed, contact = height+velocity heuristic on the reference (holosoma thresholds); non-circular masks reported in the repo
Penetrationfraction of frames with any foot body > 1 cm below z=0 (OmniRetarget tolerance)
CIsbootstrap over per-clip means, 2000 resamples
Same-code scoringstudent and teacher scored by the identical metric implementation (snmr/metrics.py)
DownstreamBeyondMimic-style tracker (holosoma, MuJoCo-Warp), phase-stratified 10-s rollouts, completion = no termination
