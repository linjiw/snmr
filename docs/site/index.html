One Latent to Retarget and Command

SNMR distills a classical IK retargeter into one skeleton-agnostic network with a shared motion latent — then shows the act-through-latent idea carries control: a co-trained 64-d command code (z_cmd) is the tracking policy's only motion input on a simulated Unitree G1. The frozen retargeting latent feeds the command prior, where its additive value is so far null on single-clip walk (an honest open thread).

The framework

Two coupled systems. Stage 1 (distill): a graph-attention encoder maps human motion to a per-frame latent z; embodiment-conditioned decoders emit joint trajectories for any of five robots. Stage 2 (co-train): a CVAE compresses the reference into a command latent z_cmd that an RL-trained tracking policy consumes as its only motion input — trained by DAgger from an explicit-command teacher inside the physics simulator.

How the latent integrates with RL training

Three findings — each one forced by an experiment — fixed the design. The final training loop alternates simulation rollouts (acting through the prior path, exactly as deployed) with supervised updates against teacher labels.

1 · A frozen latent is ignored; RL alone collapses.

Concatenating frozen z beside the explicit command is null-to-harmful (our E36: −10pp; the vanishing-influence mechanism independently replicated by UniTracker's ablation). A frozen latent as the sole command tops out at 0.72 (our E37, replicated 0.72–0.77 across 3 seeds); RL-from-scratch through a latent collapses in the literature (UniTracker, BFM). The latent must be co-trained under the control objective by distillation — pure DAgger, no RL gradient mixed in.

2 · The posterior must be a residual on the prior; train on the path you deploy.

The encoder's mean is μ_prior + residual with a tied fixed σ, giving a closed-form KL ‖residual‖²/2σ². Rollouts are collected while acting through the prior (deployment path) with episodic noise — when we collected along the privileged posterior path instead, deployment collapsed to 0.001 while the posterior path scored 0.84. Fixing the collection path alone recovered only 20× — the prior also needed the goal (finding 3).

3 · The prior needs the goal.

A prior over proprioception alone (or proprioception + frozen z) cannot anticipate the motion — 0.02–0.05 completion. Conditioning the prior on the deployable reference window lifts it to 0.944; adding the SNMR z stream gives 0.952; its completion gain is null across seeds, though D's seed variance was 4× tighter (n=3, suggestive only). The information bottleneck stays honest: the goal enters only the prior, never the decoder.

Trackability parity (GMR-paper protocol)

Matched tracking policies trained on SNMR references vs the IK teacher's: 86.7% = 86.7% completion (point-equal; 3 seeds per source × 2 eval seeds × 100 rollouts), joint RMSE noninferior (+0.33%, CI [−3.1%, +4.9%]). Formal noninferiority on completion was not established — the ±6pp CI exceeds the preregistered −5pp margin at this seed count; a power statement, not a quality gap. Details.
